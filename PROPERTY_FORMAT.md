# Единый формат объектов DARS CAPITAL

Все 48 объектов используют общий компонент карточки и одну таблицу характеристик. Данные в `frontend/src/data/properties.json` остаются источником истины.

Порядок характеристик: тип объекта, формат сделки, стоимость, площадь, комнаты (для жилья), участок (для домов), этаж (для квартир), высота потолков при наличии, адрес, статус. Отсутствующие значения показываются как «Уточняется», неизвестная цена — «Цена по запросу». Земельные участки не получают число комнат. В поиске 1 сотка равна 100 м². У аренды указывается период «/ мес.».

Описание каждого объекта хранится в `description_sections` с четырьмя разделами:

1. Об объекте.
2. Планировка и оснащение.
3. Территория и инфраструктура.
4. Расположение.

Каждый раздел содержит массив `paragraphs`. Пустые разделы показывают приглашение уточнить сведения у консультанта. Поле `description` содержит тот же текст в обычном текстовом формате для существующих интеграций. При редактировании объекта обновляйте оба представления. Исходные фактические поля, фотографии и особенности сохранены; новые сведения о недвижимости не добавлялись.

## Требует уточнения у владельца каталога

- Объект №50: заголовок сообщает 14,5 сотки, особенности — 14,3 сотки. Значения сохранены до подтверждения точной площади.
- Объект №76: 148 м² включает дополнительное пространство; в особенностях отдельно указаны площадь квартиры 116,9 м² и основная площадь 112,8 м². Важно подтверждать состав площади при консультации.

## Проверка

- `CI=true yarn test --watchAll=false --runInBand` — проверки всех объектов, неизвестных значений, участков и аренды.
- `yarn build` — production-сборка и генерация SEO-страниц.
- Используйте Node.js 20 или новее и менеджер Yarn, закреплённый в package.json. Репозиторий содержит yarn.lock.
